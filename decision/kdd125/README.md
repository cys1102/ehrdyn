# KDD125 lineage-consistent development release candidate

This additive package is generated from KDD097/KDD098R and final KDD121--KDD124-v2 aggregate artifacts. The earlier manuscript package and all upstream receipts remain unchanged. AF/flutter is an exclusion receipt, not a performance placeholder.

P is next-state dynamics; R is reward/outcome; T is trajectory termination/censoring and is not 90-day mortality. H1/H4/H8 are defined in the manuscript. The package reports reliability-qualified retrospective OPE without a real-EHR policy winner.
