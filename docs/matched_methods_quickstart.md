# Matched methods and OPE quickstart

`ehrdyn-icu fitted-synthetic-smoke` runs the complete small-scale
matched workflow. The credentialed `fitted-simulator --mode evaluate` route
runs the same 21 methods and six estimators inside the locally fitted
simulator. The fitted and controlled inventories are identical. Severity is
not a benchmark method. Credentialed result tables are local audit output, not
release assets.
